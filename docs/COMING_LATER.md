## super_admin — Platform Setup
- **Academic Calendar Model** — Configure the June-April school year separately from the April-March financial year used for receipts.
- **Franchise Management** — Centralized administrative oversight, asset sharing, and brand compliance for franchise chains.
- **White-Label Branding** — Configure custom logos, domain names, color themes, login portal banners, and email header templates.
- **Automated Trigger Rules** — Set trigger conditions for instant automated notifications on absence, fee due, or bus delay.
- **Email Server (SMTP) Integration** — Configure SMTP credentials, send grid settings, DKIM/SPF verification, and email dispatch logs.
- **SMS Gateway Integration** — Configure gateway API credentials, sender IDs, DLTI templates, and SMS delivery logs.
- **WhatsApp API Integration** — Connect WhatsApp Business API, manage template approvals, automated triggers, and delivery logs.
- **Data Backup & Restore** — Schedule automated cloud database backups and manage point-in-time recovery archives.
- **Biometric Device Integration** *(advanced)* — Connect biometric fingerprint, facial recognition, and RFID hardware machines via IP/Webhooks.
- **GPS Hardware Integration** — Configure bus GPS tracker hardware protocols, IMEI mapping, and refresh intervals.
- **Meritto / LeadSquared Sync** — Map lead sources, counselor assignments, and multi-touch lead status sync with external CRMs.
- **Payment Gateway Connectors** — Manage credentials for Razorpay, Paytm, CCAvenue, BillDesk, Easebuzz, and CCAvenue.
- **Tally ERP / Prime Connector** *(advanced)* — Configure ledger XML exports, cost-center mapping, and automated batch voucher sync.
- **Virtual Classroom Integration** — Connect Zoom, Google Meet, and Microsoft Teams tenant accounts for seamless live streaming.
- **Board Affiliation & Disclosure** — Maintain CBSE/ICSE/State affiliation numbers, mandatory public disclosure documents and renewal dates.
- **Child Info Portal Sync** — Map school and student records to the Telangana Child Info portal register and reconcile differences.
- **DigiLocker Issuer Integration** *(advanced)* — Register as a DigiLocker issuer and push transfer certificates, report cards and mark sheets as verifiable documents.
- **District & Mandal Master** — Maintain state, district, mandal and village/ward codes used by every government return.
- **SQAA Framework Management** *(advanced)* — Configure School Quality Assessment and Assurance standards and self-assessment checklists.
- **School Management Type** — Classify each campus as Government, Aided, Private Unaided, Model School, Gurukul or KGBV for state reporting.
- **State Board Configuration** *(advanced)* — Select the state education board (BSE Telangana SSC, TSBIE Intermediate, CBSE, ICSE) and its grading and assessment rules.
