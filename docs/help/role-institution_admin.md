# Using the app as Institution Admin / Principal

The whole school. You approve what others raise, set what everybody else works inside, and read the counts that say whether it is going well.

You have 91 screens. They are grouped the way the sidebar groups them: a workspace holds sections, and a section holds the screens themselves. Your workspace key is `institution_admin`, which is the first part of every address in this role.

Each entry below is the name you will see in the sidebar, followed by what that screen is for and the data it can reach.
