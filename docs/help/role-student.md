# Using the app as Student

Your own timetable, attendance, results, fees and documents.

You have 11 screens. They are grouped the way the sidebar groups them: a workspace holds sections, and a section holds the screens themselves. Your workspace key is `student`, which is the first part of every address in this role.

Each entry below is the name you will see in the sidebar, followed by what that screen is for and the data it can reach.

## Academics

### Attendance

**Attendance.** Overall, subject-wise and date-wise attendance; leave/correction request if institution allows.

- Where to find it: Sidebar → Academics → Attendance → Attendance
- What it can see: Self only
- Also visible to: admissions, faculty, finance, hod, hr, institution_admin, operations, parent, seller_admin, super_admin

### Exams & Results

**Board Hall Ticket Download.** Download the BSE Telangana or TSBIE hall ticket once the board accepts the nominal roll.

- Where to find it: Sidebar → Academics → Exams & Results → Board Hall Ticket Download
- What it can see: Specific student
- Also visible to: admissions, faculty, finance, hod, hr, institution_admin, operations, parent, seller_admin, super_admin

**Digital Hall Ticket Verification QR.** Student hall tickets include secure QR codes scanned by exam invigilators to verify student identity.

- Where to find it: Sidebar → Academics → Exams & Results → Digital Hall Ticket Verification QR
- What it can see: Specific student
- Also visible to: admissions, faculty, finance, hod, hr, institution_admin, operations, parent, seller_admin, super_admin

**Exams & grades.** Exam schedule, marks, grades, published results and report cards.

- Where to find it: Sidebar → Academics → Exams & Results → Exams & grades
- What it can see: Self only
- Also visible to: admissions, faculty, finance, hod, hr, institution_admin, operations, parent, seller_admin, super_admin

### Homework

**Homework & assignments.** View due/overdue/submitted work; submit files/text where enabled.

- Where to find it: Sidebar → Academics → Homework → Homework & assignments
- What it can see: Self only
- Also visible to: admissions, faculty, finance, hod, hr, institution_admin, operations, parent, seller_admin, super_admin

### Timetable

**Timetable.** Daily/weekly class timetable and exam timetable.

- Where to find it: Sidebar → Academics → Timetable → Timetable
- What it can see: Self only
- Also visible to: admissions, faculty, finance, hod, hr, institution_admin, operations, parent, seller_admin, super_admin

## Fees

- Where to find it: Sidebar → Fees → Fees
- What it can see: Self only
- Also visible to: admissions, faculty, finance, hod, hr, institution_admin, operations, parent, seller_admin, super_admin

## Home

### Home

**Action reminders.** Overdue assignment, attendance risk, unpaid fee, pending request or upcoming exam.

- Where to find it: Sidebar → Home → Action reminders
- What it can see: Self only
- Also visible to: admissions, faculty, finance, hod, hr, institution_admin, operations, parent, seller_admin, super_admin

**My day.** Next class, attendance %, assignments due, upcoming exam, fee due and latest announcement.

- Where to find it: Sidebar → Home → My day
- What it can see: Self only
- Also visible to: admissions, faculty, finance, hod, hr, institution_admin, operations, parent, seller_admin, super_admin

## School

**Announcements & messages.** Institution/class announcements and permitted teacher communication.

## Profile

### Profile

**Profile.** View personal/enrollment information and submit allowed update requests.

- Where to find it: Sidebar → Profile → Profile
- What it can see: Self only
- Also visible to: admissions, faculty, finance, hod, hr, institution_admin, operations, parent, seller_admin, super_admin


If a screen listed here is not in your sidebar, it is because nothing has been assigned to you for it yet -- a teacher with no section, a head of department with no department. The permission is real and the workspace is empty; ask the office to make the assignment rather than waiting for a release.
