# Feature reference

Every feature in the catalog: **442 features** across **10 roles** and **58 workspaces**. **226** have a working screen and endpoint; the rest are registered with their permission and data scope, navigable, and render an explicit "catalogued, not implemented" page.

Generated by `scripts/gen_docs.py` from [edu_features.csv](edu_features.csv) and the SPA's component registry. Do not edit by hand — run `make docs`.

## How to read this

| Column | Meaning |
|---|---|
| **Feature** | The screen, as named in the source catalog. |
| **Permission key** | Row in `permissions`, granted through `role_permissions`. The API gates on it and the SPA builds navigation from it. |
| **Scope** | The data boundary. See below. |
| **Tier** | How prominent it is in navigation. `core` is listed normally; `advanced` sits behind a disclosure in its group; `optional` is catalogued and routable but never in default navigation. Tier never affects authorisation. |
| **Status** | ✅ built · ○ catalogued |
| **Screen · API** | The React component behind a built feature and the endpoints it calls, read from the component's own source. |

## Navigation shape

A role owns **workspaces**; a workspace holds **groups**; a group holds features. That nesting is the navigation itself — a person sees only the workspace names in their sidebar, and the groups appear when they open one.

## Data scopes

| Scope | Boundary | Enforced by |
|---|---|---|
| **Platform** | Every institution. Requires `app.is_platform_admin`. | Postgres RLS |
| **Institution** | The caller's tenant. Enforced by Postgres RLS. | Postgres RLS |
| **Campus** | Campuses named on the user's role assignments. | `internal/scope` + explicit SQL predicate |
| **Department** | Departments where `departments.head_user_id` is the caller. | `internal/scope` + explicit SQL predicate |
| **Assigned classes** | Sections the caller teaches or is class teacher of. | `internal/scope` + explicit SQL predicate |
| **Self** | The caller's own student record. | `internal/scope` + explicit SQL predicate |
| **Linked children** | Students the caller is a guardian of. | `internal/scope` + explicit SQL predicate |

RLS covers only the tenant boundary. The four narrower scopes are enforced in the application, because every row involved belongs to the same institution and the `tenant_isolation` policy admits all of them. A handler that forgets its scope filter leaks data *within* a tenant — which is why `internal/scope` returns `FALSE` for an empty set rather than omitting the clause.
