# Screenshots — you must capture these (I cannot take real device screenshots)

Play requires **at least 2 phone screenshots**; up to 8. They are the single biggest
factor in whether a parent installs, so make them real screens with realistic demo data.

## Specs (Play Console rejects anything outside these)
- Format: **PNG or JPEG**, no alpha needed
- Size: **≤ 8 MB each**
- Aspect: **9:16 (portrait)** for phones — e.g. 1080×1920, 1080×2340, 1170×2532
- Each side between **320 px and 3840 px**; long side ≤ 2× short side
- No device frames with transparent corners; a plain full-bleed screenshot is fine
- Optional: 7-inch (1200×1920) and 10-inch (1600×2560) tablet sets if you want the tablet listing

## Recommended set (in this order — the first two show in search results)
1. **Parent Home** — the child's day: attendance, fees due, homework, notices (child switcher visible)
2. **Fees & payments** — dues, a receipt, the UPI QR card
3. **Wallet** — balance and history (Phase 1/2 digital money)
4. **Attendance** — the month view
5. **Bus** — the live map with the child's stop
6. **Homework / Results** — a report card
7. **Notices / Messages**
8. **Teacher: Take attendance** (optional, shows the staff side)

## How to capture cleanly
1. Sign in to the **demo school** (see `../../app-access.md`) on a phone with the
   installed app — status bar showing full battery/signal, clock at a tidy time (e.g. 9:41).
2. Android: **Power + Volume-down**. Files land in `Pictures/Screenshots` or `DCIM/Screenshots`.
3. Do not include real students' names or photos. Use the fictitious demo data.
4. Light theme, default text size, English (India) locale.
5. Copy the PNGs into this folder named `01-home.png`, `02-fees.png`, … and upload in that order.

## Optional captions (Play does not support captions; bake them in only if you make framed marketing images)
Keep the plain screenshots as the primary set; framed/annotated versions are extra work with little review benefit.
